# Modelagem de Objetos para Banco de Dados 🗄️

## 📘 O que é
Projeto de modelagem de banco de dados usando diagramas ER e tabelas relacionais, representando entidades e suas relações em um contexto acadêmico.

## 🛠 Tecnologias
- MySQL
- MySQL Workbench
- Modelagem de dados (ER)

## 🚀 Como visualizar
1. Abra o MySQL Workbench ou outro software de modelagem ER.
2. Importe o arquivo de diagrama ou siga as instruções do repositório.
3. Explore as entidades, relacionamentos e regras de integridade.

## 📌 Funcionalidades
- Diagrama ER completo
- Estrutura de tabelas com chaves primárias e estrangeiras
- Regras de integridade e relacionamentos

## 🧠 O que aprendi
- Modelagem de dados relacional
- Criação de diagramas ER
- Planejamento de banco de dados para aplicações reais
